# Pickers

This page explains the three search menus. It assumes you are comfortable
pressing shortcuts in Sway and nothing else. A _picker_ is a menu that lists
items and filters them as you type. Type a few letters and press `Enter` to
choose.

Use the following table to open the picker you need.

| Shortcut          | Picker               |
| :---------------- | :------------------- |
| `Super+d`         | Launcher             |
| `Super+Control+v` | Clipboard history    |
| `Super+Control+n` | Notification history |

## Open programs with the launcher

Press `Super+d`, type part of a name, and press `Enter` to launch it. The
launcher matches your active theme on its own, so it follows Flint or Sand
without extra steps.

## Reuse clipboard history

Your copies are kept from login on, so an older entry is still there after you
copy something new. Press `Super+Control+v` and use the following steps to bring
one back:

1. Type part of the entry to filter the list.
2. Check the preview pane for the full text or image.
3. Press `Enter` to copy the selected entry and close the picker.

Press `Escape` to close the picker without copying anything. If the picker is
already open, the same shortcut brings it forward instead of opening a second
copy.

## Revisit notifications

Dismissed messages stay available for a second look. Press `Super+Control+n` to
browse them, and select an entry to show it again for five seconds. When there
is no history, you get a short notice instead of an empty menu.

Three shortcuts manage the current popup without opening the menu. Use the
following list to handle it:

- Press `Super+n` to dismiss one notification.
- Press `Super+Shift+n` to dismiss all notifications.
- Press `Super+Control+n` to browse the history as described in the preceding
  paragraph.

## Answer confirmation menus

The power shortcuts and the login session prompt reuse the same `fuzzel` menu
with two options instead of a search list. Press `Enter` to confirm the
highlighted option and `Escape` to cancel. Cancelling a power action does
nothing, and cancelling the session prompt starts fresh.
