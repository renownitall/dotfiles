# Themes

Edit colors in `meta/color-scheme.md`, then run `make dark` or `make light` to
regenerate the palette data and apply the configuration. `$mod+Shift+t` toggles
between dark and light mode. Use `sw` to manage wallpapers: `sw --set` sets a
given image as the wallpaper, `sw --next` rotates to the next wallpaper, and
`sw --restore` re-applies the last wallpaper.
